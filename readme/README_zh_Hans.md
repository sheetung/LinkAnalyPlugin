# LinkAnaly

对聊天中的链接进行解析,以及针对未解析网站截图发送

## 支持的链接

1. BiliBili
2. Github
3. Gitee
4. 其他网站的截图功能（插件配置处手动开启）

## 更新历史

- v1.0.1 增加网站截图功能
- v0.2.2 完善基础功能开发并优化显示
